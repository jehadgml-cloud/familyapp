# 🕋 صناديق وجباية عائلة آل اطفيحة (CEMS-ATFIHAH)

بوابة إلكترونية متكاملة للتدقيق والاعتماد المالي وجباية الصندوق الشهري لعشيرة آل اطفيحة. تطبيق ويب مبني بأقوى التقنيات ومأمن بالكامل لضمان سرية البيانات ومرونة التصفح من مختلف الأجهزة الذكية.

---

## 🚀 التقنيات المستخدمة

*   **Next.js 14 (App Router)** & **TypeScript**
*   **Tailwind CSS** (تصميم متجاوب بالكامل ودعم كامل للغات الـ RTL)
*   **Supabase** (قاعدة بيانات PostgreSQL، المصادقة الأمنية، التخزين السحابي للمستندات)
*   **React Hook Form**
*   **Progressive Web Application (PWA)** (دعم التثبيت على الجوال ووضع العمل دون اتصال)

---

## 🛠️ تنصيب المشروع محلياً

### 1. المتطلبات
تأكد من تنصيب بيئة العمل التالية على جهازك:
*   [Node.js](https://nodejs.org) (إصدار 18 فما فوق)
*   حساب مجاني على [Supabase](https://supabase.com)

### 2. تحميل الاعتمادات وبدء التشغيل
1. افتح موجه الأوامر في مجلد المشروع وقم بتنفيذ الأوامر التالية:
   ```bash
   npm install
   ```
2. قم بإنشاء ملف باسم `.env` بناءً على النموذج المرفق في `.env.example` وأدخل مفاتيح الاتصال بخوادم Supabase الخاصة بك:
   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://xxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9...
   SUPABASE_SERVICE_ROLE_KEY=your-service-role-key
   ```
3. ابدأ خادم التطوير المحلي:
   ```bash
   npm run dev
   ```
4. افتح المتصفح على الرابط: `http://localhost:3000`

## 🏁 إعداد قاعدة بيانات Supabase

لتشغيل الخصائص بالكامل بنجاح، قم بتشغيل كود SQL الموجود في ملف `schema.sql` في تبويب **SQL Editor** في لوحة تحكم مشروعك على Supabase.

### 🔒 سياسات الحماية و RLS
تم تفعيل خاصية Row Level Security على جميع الجداول لمنع أي وصول غير مصرح به:
*   لا يمكن لأي مستخدم خارج القسم المالي (Department) تعديل البيانات.
*   بيان المصاريف لا يعدله ويعده إلا مخول إدخال البيانات (Data Entry User).
*   مراجعة وإمضاء التقارير تتم عبر المشرفين والمدققين الموثقين.

## 📱 التثبيت كـ تطبيق للجوال (PWA)

التصفح على هواتف الأندرويد والآيفون يدعم التثبيت المباشر على الشاشة الرئيسية (Add to Home Screen):
1. افتح الموقع من الجوال عبر متصفح Safari (في الآيفون) أو Chrome (في الأندرويد).
2. اضغط على خيار **مشاركة (Share)** ثم اختر **إضافة إلى الشاشة الرئيسية (Add to Home Screen)**.
3. سيظهر التطبيق بأيقونة العائلة الرسمية وبواجهة سريعة ملائمة لأبعاد شاشتك وبدون إطار المتصفح التقليدي.

---

## 🌐 ربط الدومين المخصص (Custom Domain)

لربط لوحة التحكم بالنطاق الخاص بك (مثال: `reports.atfihah.com`):
1. اذهب للوحة تحكم [Vercel](https://vercel.com).
2. اختر مشروعك ثم اذهب إلى **Settings ⬅️ Domains**.
3. أضف النطاق المراد ربطه ثم قم بتهيئة سجلات الـ DNS (CNAME و A records) في لوحة تحكم النطاقات الخاصة بك كما هو موضح بالتعليمات.
4. بمجرد التحقق وسحب شهادة الأمان SSL بنجاح، قم بتحديث سجلات توجيه المصادقة في لوحة تحكم Supabase تحت **Authentication ⬅️ URL Configuration** لتشير للنطاق الجديد بدلاً من localhost ليعمل تسجيل الدخول وسحب الجلسات بشكل سليم.
